# PK WMS Mobile QA — 2026-10-09

## Fixed

- Pallet copy now allows the source position to be selected as a destination (e.g. U/U-02 → U/U-02). It appends a new receipt while preserving the original item and history; the destination checkbox explicitly labels the source as adding a new item.
- Copy opening focuses the form and scrolls it into place without automatically focusing/opening the native destination select during a smooth scroll.
- Copy fields use 16px on mobile; native selects are excluded from text-keyboard layout detection.
- Source version is checked against the current version map; stale source/destination and duplicate destination checks remain.
- Browser regression lookup for copy conflicts is scoped to the visible copy status, rather than the intentionally hidden sync strip.
