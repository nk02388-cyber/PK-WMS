# PK WMS review — 2026-10-07

## Fixes

- Unchanged periodic account refresh no longer dispatches account-changed or rewrites the current auth stage. This avoids unnecessary dependent UI work and keeps focus/forms stable.
- Expired/failed sessions clear user management, credential drafts, stale account status and menu access. Identity/role changes clear management drafts too.
- User-list responses carry a request generation and actor name so an older request cannot overwrite newer results or another account's screen.
- Account requests time out after 20 seconds and restore the form controls with a retry message.
- Edge Function rejects null/array/non-object and oversized JSON bodies with 400 instead of crashing.
- Updated department DOM fixtures and full-menu browser fixtures for the new Settings page.

## Verification

- 80 unit tests: balances, depletion/history retention, receive/issue/return/move/copy, search/FIFO, BOM/recipes/plans, reorder, cycle counts, scrap, receipts, calendar, notifications, department/login, geometry and rotation.
- Admin credential handler tests: creation by role/login kind, new credential accepted/old PIN rejected, non-admin denied, invalid/oversized request rejected. Auth calls mocked.
- Full-menu WebKit smoke: 16 ordinary menus at 1440/768/390 px, no page errors or page overflow. M1 22 pallets/T1 context 18 pallets; edit/issue/return forms open and focus correctly.
- Settings: Admin and user at 1440/390; credential confirmation mismatch, reset, Admin password creation and permission exclusion.
- Sidebar: 1440/950/390; logo, collapsed icons, focus/drawer navigation.
- Map toolbar: WebKit 430/390/320 portrait and 932 landscape; controls do not overlap map; fullscreen/rotate/zoom/exit pass.
- Detail map: canvas 2048×1583, native gesture guard, 35 G1 slots, rotation/close/reopen pass.
- Copy: WebKit 390/1440 with simulated batch save/version conflicts; source remains unchanged.
- Motion: WebKit 1440/390, finite animations, stable metrics and reduced-motion behavior.
- Destructive confirmation: identity, wrong password, reason required, audit failure, single replay and ordinary Cancel controls.
- Operations PIN: wrong/correct PIN, cancel, keyboard, relock and Admin-only entry. Print renderer: long/escaped material content and empty report.
- Typography: local Noto Sans Thai loaded; 14px menus/table and equal-width numeric digits, desktop/mobile and embedded operations.
- Local referenced assets checked; no missing files. Production login rejection checked without signing into or editing a real account.

## Limits

Tests use isolated fixture data and mocked backend writes. No real staff password or production inventory was changed. Physical iPhone gestures/keyboard, camera scanning, actual printer output and concurrent devices on unreliable networks still require real-device verification. This review does not assert that every possible bug is absent.
