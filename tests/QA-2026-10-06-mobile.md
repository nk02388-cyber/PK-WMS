# Mobile map interaction audit — 2026-10-06

Changes: map pointer updates are coalesced to one write per animation frame. Pinch gestures reuse their viewport geometry until pointers change. Zoom panning translates existing pallet/label overlays without recalculating each slot or resizing the background. The background continues to cover the viewport. Scale, rotation, viewport and slot-data changes invalidate the layout cache. Closing the viewer cancels pending gesture work. Small-screen modal background blur is disabled.

Verification: `node tests/map-gestures.test.cjs` covers pinch anchoring, limits, finger replacement, drag/tap isolation, cancellation and a 200-event burst producing one paint. `node tests/mobile-map-performance.cjs` checks unchanged pallet styles during pan, exact screen-space displacement, all four rotations and scale invalidation under 6x CPU throttling. `node tests/browser-stability.cjs` checks all 15 non-operations tabs and edit/withdraw/return forms at 390, 768 and 1440 pixels. The unit suite passed 77 tests.

Before/after profiling of 120 synchronous pan updates with forced layout in an isolated Edge fixture at 390px and 6x CPU throttling: 37,289ms before, approximately 4,162ms after. This is a workload comparison, not a measured phone frame rate. The fixture uses repository snapshot data, blocks remote writes, and does not change production inventory.

Limits: browser emulation does not verify physical Android/iPhone hardware, the on-screen keyboard, mobile Safari rendering or weak-network database synchronization. Production source deployment is checked separately; no live stock mutations are used for this audit.

## Follow-up after reported freezing

Mobile no longer builds the approximately 1,000 CAD replacement labels for other zones. The selected zone's interactive pallet labels remain. Mobile pinch now scales prepared overlays and recalculates their layout once when the gesture ends, while maintaining image alignment in all four rotations. JPEGs were extracted byte-for-byte into separate cacheable files (no change to map artwork). The detail source is loaded lazily. Fixed the close handler's incorrect gesture-controller name and added close/reopen assertions.

Repeated 6x CPU fixture: 120 pan updates approximately 110ms; 60 scale updates approximately 47ms. These are synchronous computation/layout workload timings, not rendered frame rates or a promise of physical-phone performance. The mobile test now checks that scale changes preserve slot styles, checks zero other-zone label nodes, closes the viewer and reopens T-1 with 18 pallets. All 77 unit tests and the three-width browser regression passed.
