## สิ่งที่ปรับ

- department-login.test.cjs: เพิ่ม DOM fixture สำหรับ insertBefore/prepend/avatar class เพื่อรองรับรูปโปรไฟล์
- ux-copy.test.cjs: ใช้ข้อความ DASHBOARD ปัจจุบัน พร้อมคงตรวจ hash ข้อมูลและภาพผังเดิม
- capacity-usage.test.cjs: ตรวจผลการเรียกฟังก์ชันจริงเมื่อข้อมูลยังไม่พร้อม แทน regex ที่ผูกกับบรรทัดเก่า
- database.integration.cjs: โหลด migration version/audit ปัจจุบัน ใช้ RPC จริงแทน direct updated_at writes เก่า และตรวจชื่อผู้ใช้จาก server
- live-readonly-browser.cjs: เพิ่มตรวจ deployment จริง หน้า entry/login และไฟล์หลัก โดยไม่ใช้รหัสบัญชีจริงหรือเขียนสต็อก

## ข้อจำกัด

การทดสอบฟอร์มที่เขียนข้อมูลใช้ fixture/backend mock หรือ PostgreSQL ในเครื่อง ไม่มีการเปลี่ยนสต็อก รหัสผ่าน รูปโปรไฟล์ หรือบัญชีผู้ใช้จริง การตรวจ production เป็น read-only และไม่ได้ล็อกอินด้วยบัญชีจริง จึงไม่ยืนยัน workflow ใบเบิกใน /operations/ ครบขั้นตอนบนฐานข้อมูล production

WebKit จำลองและ CPU throttling ไม่ใช่ iPhone 15 Pro Max เครื่องจริง ยังต้องทดสอบ touch/keyboard กล้องสแกน เครื่องพิมพ์ และการเชื่อมต่อจากหลายเครื่องบนเครือข่ายจริง RM/FG เป็นเว็บไซต์แยก ไม่อยู่ในชุดทดสอบ PK WMS รอบนี้ ผลผ่านไม่หมายความว่าไม่มีบัคที่เป็นไปได้ทั้งหมด
