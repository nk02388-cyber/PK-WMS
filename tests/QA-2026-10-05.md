## Limits

This is a broad regression audit, not proof that every possible bug is absent. Authenticated production database writes, physical mobile keyboards, camera scanning, actual printers and multi-device realtime over unstable networks were not exercised. The browser tests isolate backend requests, and live entry checks cover the public signed-out flow.
