# Noto Sans Thai

Variable WOFF2 fonts for weights 400–700, obtained from the Google Fonts CSS API on 2026-10-06. Thai, Latin and Latin Extended subsets are served locally through `typography.css` with `font-display: swap`. Total font files are approximately 74 KB; browsers load the subsets required by the displayed characters.

Source: https://fonts.googleapis.com/css2?family=Noto+Sans+Thai:wght@400..700&display=swap
